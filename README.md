# Personal CV Website
This repository contains my personal CV website, created as a college assignment. 
The site is built using clean HTML and CSS, featuring a responsive layout to showcase my professional profile, education, and skills.

You can view the live website here: https://hastenorama.github.io/

## Technologies Used
- **HTML5** – Structured content and semantic elements
- **CSS3** – Custom styling, layouts, and design
- **GitHub Pages** – Web hosting and deployment

## Project Structure
- index.html - The main structural file of the website
- style.css - The stylesheet containing all page layouts
- images folder - Folder containing the profile photo
